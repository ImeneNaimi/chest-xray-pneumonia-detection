# Chest X-Ray Pneumonia Detection

A deep learning project for detecting pneumonia from chest X-ray images using a Convolutional Neural Network (CNN) developed with TensorFlow and Keras.

##  Project Overview

Pneumonia is a respiratory infection that can be identified through abnormalities visible in chest X-ray images. This project explores the use of deep learning and computer vision techniques to automatically classify chest X-ray images as **Pneumonia** or **Normal**.

The project was developed as part of an academic study of Artificial Intelligence, deep learning and data security.

## Objectives

- Apply deep learning to medical image classification.
- Build and train a Convolutional Neural Network (CNN).
- Preprocess and prepare chest X-ray images for training.
- Evaluate the performance of the trained model.
- Visualize training results and model performance.

##  Technologies

- **TensorFlow**
- **Keras**

- **Convolutional Neural Networks (CNN)**
